# 查看复习词库

在首页选择日语或英语，点击“复习词库”。只有回到首页才能切换语言，两种语言的词组和记忆状态独立。

- 直接导入复习库、尚未作答的旧词显示“待测”，优先排列；不会伪造已掌握记录。
- 学习完成的词形自动建立首次记忆评价和下次复习时间。某个词形曾答错，即使本轮后来答对，首次评价仍保留错误影响。
- 卡片按风险排列；点击卡片，在右侧查看各词形的预计保持率、下次时间及评价／错误次数。时间按本机时区显示。
- 一个词组无论有多少成员和词形，只计一个词。未学过的词形显示“尚未评价”，不等于已经启用或逾期。
- “刷新”重新读取当前数据；读取期间可“取消读取”或“返回”。读取失败可再次刷新，不会修改用户进度。

当前入口只交付词库浏览与风险查询，不是复习答题；查看不会完成每日复习或打卡。复习答题、复习计划和错题重练仍在后续切片接通。
