# 配置复习计划

1. 首页选择日语或英语，进入“复习计划与词库”。页面内不切换语言，两门语言的设置分别保存。
2. 调整每日复习目标与每轮最多词数。整组不论词形多少仍计一个词；整数滑块支持方向键调节。
3. 勾选词形、题型和书写要求，每类至少一项。无常用汉字的日语词不会出汉字题，英语使用英文字母。
4. 选择“全部词库”或“指定词组”。全部包含以后加入的复习词组；指定范围逐组勾选或全选，至少保留一组。
5. 英语可选语法名称或示例动词范式。查找离线动词并按中文义项选择；示例必须覆盖启用词形，提示不显示待答单词的答案。
6. 点击“保存计划”。失败会显示原因且保留原计划；“重新加载”会放弃未保存修改，恢复已保存内容。

勾选只控制范围，不删除单词或记忆。点击词组查看可用词形；“删除当前词组及进度”需要单窗口确认，确认后整组及学习、记忆、答题记录一并删除，不归档。

后台读写期间可取消或返回。重开与重启仍保留已保存计划，不改变学习计划。
