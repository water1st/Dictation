# 导入文本词表

在首页选择日语或英语，打开“批量导入词表”。词库按源语言查询，不能输入中文反查。

1. 粘贴词表并点击“匹配词表”，或使用“选择 TXT”。也可以拖入一个 TXT 文件。
2. 每行一个日文或英文词形，使用 UTF-8 编码；空行及以 `#` 开头的注释会忽略。相同输入只保留首次出现的行。
3. 单义项默认选中；多义项需要查看中文释义、词性和词形后选择。未匹配项保留在列表中，不会被猜测成其他词。
4. 用勾选框选择要暂存的词语。“全选已确认义项”只选已有义项选择的行，不替你决定多义词。
5. 点击“加入收件箱”，再打开收件箱决定送到学习、复习还是丢弃。缺少中文释义的成员可在收件箱详情补充。

导入一个变形会带入对应整组词形，已有词组会忽略。导入页不直接创建学习或复习进度。

程序目录的 `Samples/日语词表.txt`、`Samples/英语词表.txt` 可直接试用。首次启动时也可指定一份词表：

```powershell
.\Dictation.Presentation.exe ".\Samples\英语词表.txt"
```

启动参数使用最后一次选择的语言。程序已运行时，再次启动仅激活原窗口并退出，不转交文件；此时请在原窗口选择或拖入文件。

无效编码、文件丢失或词库不可用会显示在当前页面，不会悄悄将部分错误结果导入。所有操作都在主窗口内完成。

匹配和暂存在后台处理，可点击“取消操作”；返回上级也会取消当前未完成的导入操作。已经提交的批次不会因取消被删除，仍可在收件箱查看。精确义项会全部列出，不因普通查词的每页数量上限而截断。
