# Review Routing

此处是适配 Dictation 的**轻量评审入口**，不包含 Project-Alone 所带 gstack 第三方大套件及其可执行 CLI。不能声称已安装 gstack 全功能、已执行其专项工具或通过其检查。

使用时：
1. 先遵守仓库 `AGENTS.md` 及对应 Rules；只在专项计划、架构、代码审查、QA、安全核查时触发。
2. 读取当次 Task、目标分支和当前实际 Diff，选择可用且已授权的实际审查手段；无能力时如实报告。
3. 不安装依赖、不创建额外工作区、不执行发布、不启用遥测；必要的第三方完整 gstack 套件须经过另行核实和授权。
4. 报告检查事实、发现的问题、对应位置与尚未验证项；不得将建议当作已经修复。
